# Alhazred State Repository

This repository contains persistent runtime state for the Alhazred campaign world.

Unlike the primary Alhazred repository, which contains:
- setting lore,
- system philosophy,
- rules,
- static locations,
- and canonical world information,

this repository contains:
- active session state,
- evolving character conditions,
- runtime journals,
- relationship changes,
- discovered clues,
- active inventories,
- temporary world mutations,
- and AI runtime artifacts.

---

# Repository Relationship

Primary setting and system repository:

https://github.com/josephweaver/alhazred

This repository acts as:
- persistent runtime memory,
- save-state layer,
- and evolving campaign continuity.

---

# Design Philosophy

The separation between:
- static world structure,
- and mutable runtime state

helps support:
- long-running campaigns,
- AI-mediated storytelling,
- branching continuity,
- experimental sessions,
- alternate timelines,
- and persistent emotional continuity.

Static lore may occasionally be promoted manually from runtime discoveries.

# Important Principle

This repository represents:

living memory.

Not all information here is necessarily:
- correct,
- complete,
- trustworthy,
- or canonized.

Some state artifacts may represent:
- survivor perception,
- incomplete records,
- unstable cognition,
- contradictory observations,
- or evolving understanding.
